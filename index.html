LANVEX

Community-Focused Minecraft • Anti Pay-to-Win

Lancasters SMP (often referred to as LancSMP) is a community-focused Minecraft server built to fight against pay-to-win gameplay. The server runs on powerful hardware and fast internet.

One of the unique parts of LancSMP is its heavy use of the Skript language, which powers many of the server's custom features and systems. In the future, players will even be able to create their own worlds, play with friends, and build custom minigames using Skript.
